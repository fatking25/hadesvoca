## 2. 현재 상태 요약

| 영역           | 현재 상태                              | 우선순위 |

| 단어장/오답노트     | 빈 상태 이미지 필요                        | 중간   |
| 공통 보상/상태 아이콘 | 코인, EXP, 북마크, streak 아이콘 필요        | 중간   |

# 7. 우선순위

| 우선순위 | 작업                   | 설명                                            |
| ---- | -------------------- | --------------------------------------------- |
| 1    | Stage 2 실전회화 이미지 29개 | `thumbnail 1개 + Day별 cutscene 7개 + scene 21개` |
| 2    | 시작/홈 대표 이미지          | 앱 첫인상 개선                                      |
| 3    | 단어 학습 결과/보상 이미지      | 완료감 강화                                        |
| 4    | 단어장/오답노트 빈 상태 이미지    | 저장 데이터 없을 때 화면 완성도 개선                         |
| 5    | 공통 아이콘               | 코인, EXP, 북마크, streak 등 반복 사용 이미지              |
