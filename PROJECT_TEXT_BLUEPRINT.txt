HadesVoca 프로젝트 텍스트 설계도
작성 기준: node_modules, dist, 개발 로그 파일은 제외하고 실제 유지보수 대상 파일 중심으로 정리.

============================================================
1. 프로젝트 개요
============================================================

HadesVoca는 Vite + React + TypeScript 기반의 모바일 우선 TOEIC 단어/실전 회화 학습 앱이다.
정적 콘텐츠는 public/content 아래 JSON과 이미지로 관리하고, 사용자 진행 상황은 브라우저 localStorage에 저장한다.
앱은 온보딩, 홈 대시보드, 단어 학습, 회화 학습, 단어장, 오답노트, 설정 오버레이로 구성된다.

주요 흐름:
- src/main.tsx -> src/App.tsx -> src/router/AppRouter.tsx
- AppRouter가 라우팅과 온보딩 보호를 담당한다.
- MobileLayout이 로그인 이후 공통 모바일 셸, 상단 상태바, 하단 탭바, 설정 시트를 담당한다.
- public/content의 JSON은 src/api/contentApi.ts에서 fetch/검증 후 화면으로 전달된다.
- src/utils/storage.ts가 사용자 진행 데이터의 저장/복원/병합을 담당한다.

18. src/utils
============================================================

src/utils/audioSettings.ts
- 오디오 설정 load/save, 기본 볼륨, 효과음 볼륨 조회.

src/utils/browserStorage.ts
- localStorage/sessionStorage 안전 접근 어댑터. try/catch와 환경 체크를 중앙화.

src/utils/contentJoin.ts
- 저장된 단어/표현 ref와 정적 콘텐츠 JSON 본문을 화면 표시용으로 join하는 헬퍼.

src/utils/conversationDifficulty.ts
- 회화 난이도 값과 UI 표시용 라벨/상태 계산.

src/utils/id.ts
- local id, 세션 nonce, UI revision 생성 유틸.

src/utils/learningUnlock.ts
- 순차 학습 해금 여부와 lesson availability 계산.

src/utils/learnStats.ts
- 사용자 진행 데이터 기반 통계 계산. 완료 수, 일일 학습 수, 진행률 등.

src/utils/random.ts
- 배열 셔플 같은 랜덤 관련 공용 유틸.

src/utils/storage.ts
- 사용자 진행 데이터의 핵심 저장/복원/정규화/병합 로직. 보상 적용, 오답, 단어장, 완료 처리 포함.

src/utils/userGrade.ts
- rankTier 기반 사용자 등급 라벨 계산.
