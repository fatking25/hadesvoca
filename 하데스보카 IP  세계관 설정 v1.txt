하데스보카 IP / 세계관 설정 v1

문서 목적:
- 하데스보카 실전회화 컷씬과 대화 콘텐츠에 사용할 5인 캐릭터 IP와 세계관을 정의한다.
- 기존 참고 캐릭터의 색상, 상징, 분위기, 성격 포인트는 참고하되,
  실제 인물/기존 버츄얼 IP를 그대로 복제하지 않는다.
- 하데스보카 전용 영어 학습 앱 캐릭터로 재창조한다.
- 이후 이미지 생성 프롬프트, 컷씬 기획, 대화 스크립트, 캐릭터별 말투 기준으로 사용한다.


==================================================
1. 하데스보카 세계관 개요
==================================================

하데스보카는 TOEIC 단어 학습과 실전회화 표현 학습을 결합한
캐릭터 기반 영어 학습 앱이다.

사용자는 매일 Day 단위의 학습을 진행하며,
5명의 하데스보카 캐릭터와 함께 일상 상황 속 영어 표현을 익힌다.

하데스보카의 실전회화는 단순 문장 암기가 아니라,
캐릭터와 함께 상황을 경험하고,
나레이션과 대화 스크립트를 따라가며,
핵심 표현을 배우고,
짧은 퀴즈로 확인하는 구조다.

세계관 핵심:
- 사용자는 하데스보카 앱에 들어온 영어 학습자다.
- 5명의 캐릭터는 사용자를 도와주는 실전회화 파트너다.
- 각 캐릭터는 특정 회화 상황에 강점을 가진다.
- 캐릭터들은 사용자가 영어로 말문을 트도록 돕는다.
- 분위기는 밝고 친근한 모바일 비주얼노벨형 학습 앱이다.
- 모든 장면은 한국 도시 일상 배경을 기반으로 한다.

세계관 톤:
- 밝음
- 친근함
- 일상적
- 학습 앱답게 안정적
- 캐릭터성은 분명하지만 과하게 판타지스럽지 않음
- 팬메이드 감성은 살리되, 정식 앱처럼 정돈된 분위기


==================================================
2. 하데스보카 캐릭터 팀 콘셉트
==================================================

팀 콘셉트:
"사용자의 영어 말문을 열어주는 5인 실전회화 파트너"

5명의 캐릭터는 각각 다른 방식으로 사용자의 학습을 돕는다.

챈나:
- 대화를 시작하게 만든다.
- 첫 만남, 약속 제안, 가벼운 질문을 담당한다.

솜주먹:
- 대화를 이어준다.
- 주문, 리액션, 티키타카, 편한 잡담을 담당한다.

키마:
- 표현을 다듬는다.
- 예약, 일정 변경, 정중한 표현, 문장 뉘앙스를 담당한다.

연초록:
- 방향을 알려준다.
- 길 안내, 위치 설명, 차분한 복습을 담당한다.

띵귤:
- 짧고 자연스럽게 정리한다.
- 카페 안부, 근황 대화, 취향 표현, 담백한 리액션을 담당한다.

3. 공통 IP 디자인 원칙
==================================================

공통 스타일:
- 밝은 캐주얼 애니메이션 스타일
- 모바일 게임 컷씬에 어울리는 비주얼 노벨식 일러스트
- 캐릭터 중심 구도
- 부드러운 조명
- 따뜻하고 친근한 분위기
- 한국 도시 일상 배경
- 과하게 어둡거나 전투적인 분위기 금지
- 너무 유아용처럼 보이지 않게 조정

공통 이미지 기준:
- 16:9 가로형 컷씬
- 모바일 화면에서 캐릭터 얼굴과 표정이 잘 보여야 함
- 배경은 상황 전달용으로만 사용
- 캐릭터와 상황이 텍스트 없이도 이해되어야 함
- 로고, 자막, 말풍선, 긴 텍스트 금지

공통 의상 방향:
- 일상복
- 카페, 식당, 거리, 학습 공간에 자연스럽게 어울리는 복장
- 캐릭터별 대표 색상과 상징 모티프만 적당히 반영
- 무대 의상, 전투복, 판타지 갑옷 느낌은 피함

공통 금지 요소:
- 실제 로고
- 실제 브랜드명
- 실제 인물/버츄얼 IP와 동일한 얼굴/의상 복제
- 방송 플랫폼 정보
- 팬덤명
- 실제 데뷔일/소속사/활동 이력
- 실제 밈 직접 사용
- 과한 노출
- 공포/폭력 분위기
- 복잡한 UI 오버레이

실제 방송 밈이나 기존 아바타의 직접적인 디테일은 사용하지 않는다.
하데스보카에서는 영어 회화를 시작하게 만드는 캐주얼 학습 파트너로 재설계한다.

- 분홍빛 또는 라벤더빛 눈 포인트

10. 캐릭터별 말투 기준
==================================================

챈나:
- 밝고 가볍게 시작한다.
- 사용자를 격려한다.
- 실수에 관대하다.
- 문장은 짧고 활기 있게 한다.

예시:
"좋아, 오늘은 한 문장만 말해도 성공이야!"
"이럴 땐 그냥 편하게 물어보면 돼."


솜주먹:
- 친구처럼 편하게 말한다.
- 리액션이 크다.
- 어려운 표현을 쉽게 풀어준다.
- 농담 섞인 말투가 가능하다.

예시:
"주문은 어렵게 생각하지 마. 이거 하나면 끝!"
"오, 이 표현 쓰면 꽤 자연스러운데?"


키마:
- 조용하고 정돈된 말투다.
- 표현의 뉘앙스를 설명한다.
- 정중한 표현을 선호한다.
- 과하게 감정적이지 않다.

예시:
"의미는 맞지만, 이 표현이 조금 더 자연스러워요."
"예약 상황에서는 정중하게 시작하는 게 좋아요."


연초록:
- 부드럽고 안정적인 말투다.
- 천천히 설명한다.
- 사용자가 헷갈릴 때 안심시킨다.
- 방향성과 순서를 잡아준다.

예시:
"괜찮아, 먼저 기준이 되는 장소부터 말하면 돼."
"길 안내는 순서대로 말하면 훨씬 쉬워져."


띵귤:
- 짧고 담백하게 말한다.
- 핵심만 짚는다.
- 무덤덤하지만 친근하다.
- 실용적인 표현을 선호한다.

예시:
"길게 안 해도 돼. 이 정도면 충분히 자연스러워."
"카페에서는 이 표현이 제일 무난해."
