하데스 보카 학습 문제 풀이 패턴 정리

목적
- 현재 단어학습과 실전회화가 어떤 방식으로 문제를 출제하는지 정리한다.
- 실전회화는 같은 표현을 여러 방식으로 반복 학습하도록 확장 방향을 제안한다.
- 단어학습은 현재 패턴을 분석만 하며, 즉시 추가/수정이 필요한 상태는 아니다.


1. 단어학습 현재 구조

관련 콘텐츠/타입
- public/content/words/stage-1.json
- src/types/content.ts
- src/pages/WordStudyDayDetailPage.tsx

콘텐츠 단위
- Stage
  - Day
    - word
      - questions[]

현재 단어 1개당 기본 문제 패턴
1) word-to-meaning
- 영어 단어를 보고 한국어 뜻을 고른다.
- 예: schedule -> 일정, 시간표
- 학습 목적: 단어 인식, 뜻 매칭

2) meaning-to-word
- 한국어 뜻을 보고 영어 단어를 고른다.
- 예: 일정을 잡다 -> schedule
- 학습 목적: 뜻에서 단어를 회상

3) fill-blank
- 예문의 빈칸에 들어갈 영어 단어를 고른다.
- 예: Please send me your ____ for next week.
- 학습 목적: 문맥 속 단어 사용 확인

현재 단어학습 풀이 흐름
1. Day에 포함된 words를 불러온다.
2. 각 word의 questions를 순서대로 quizItems에 넣는다.
3. 사용자는 4지선다 선택지를 고른다.
4. 정답 확인 후 정답/오답 피드백을 본다.
5. 마지막 문제 후 결과 화면으로 이동한다.
6. 결과 화면에서 완료, 보상, 오답, 복습 상태가 저장된다.

단어학습 패턴 평가
- 장점: 인식 -> 회상 -> 문맥 적용 순서가 분명하다.
- 장점: 단어 1개를 최소 3회 다른 방식으로 반복한다.
- 장점: 현재 MVP 기준으로 충분히 안정적인 구조다.
- 한계: 모두 선택형이라 직접 타이핑/철자 회상은 없다.
- 판단: 지금 단계에서는 단어학습 문제 유형을 추가하지 않아도 된다.


2. 실전회화 현재 구조

관련 콘텐츠/타입
- public/content/conversations/stage-1/index.json
- public/content/conversations/stage-1/day-01.json ~ day-07.json
- src/types/conversation.ts
- src/pages/conversation/ConversationDayDetailPage.tsx
- src/pages/conversation/ConversationDayResultPage.tsx

콘텐츠 단위
- Stage
  - index.json(dayFiles)
  - Day
    - narrations[]
    - dialogue[]
    - keyExpressions[]
    - quiz[]

현재 Day 진행 흐름
1. 컷씬
- 장면 이미지와 상황 설명을 본다.

2. 나레이션
- 상황 배경을 한 문장씩 읽는다.

3. 대화 스크립트
- 대화를 한 줄씩 공개하며 읽는다.

4. 핵심 표현
- expressionEn, expressionKo, tipKo를 카드로 본다.
- 사용자는 표현을 단어장에 저장/해제할 수 있다.

5. 표현 퀴즈
- 현재 타입은 multiple-choice 하나다.
- 사용자는 상황/의미에 맞는 선택지를 고른다.

6. 결과
- 퀴즈 점수 표시
- Day 완료 저장
- 틀린 표현 퀴즈 ID를 오답노트에 저장

현재 실전회화 문제 패턴
1) multiple-choice
- 상황 또는 의미에 맞는 영어 표현을 4지선다로 고른다.
- 학습 목적: 표현 인식, 상황 매칭

현재 실전회화 패턴 평가
- 장점: 상황 -> 대화 -> 표현 -> 퀴즈 흐름이 자연스럽다.
- 장점: 에피소드형 회화 느낌을 만들기 좋다.
- 장점: 표현 저장과 표현 오답 저장이 연결되어 있다.
- 한계: 실제 발화, 문장 조립, 대화 응답 선택 경험은 약하다.
- 한계: 같은 표현을 여러 방식으로 반복하지 않아 학습 밀도가 낮다.
- 판단: 현재는 "회화 학습"이라기보다 "상황형 표현 읽기 + 선택형 퀴즈"에 가깝다.


3. 실전회화 추천 문제 유형

추천 원칙
- 선택형만 유지하지 않는다.
- 같은 핵심 표현을 여러 방식으로 반복시킨다.
- 음성/TTS/AI 없이 구현 가능한 문제부터 먼저 둔다.
- 한 Day 안에서 2~3개 핵심 표현을 짧게 반복한다.
- 문제 유형은 쉬운 인식형에서 어려운 회상형으로 진행한다.

추천 Day 학습 패턴
1. 장면 이해
- 컷씬과 나레이션으로 상황을 이해한다.

2. 대화 읽기
- 대화를 한 줄씩 따라가며 맥락을 본다.

3. 핵심 표현 확인
- 오늘의 표현 2~3개를 카드로 정리한다.

4. 표현 반복 퀴즈
- 같은 표현을 아래 유형 중 3~5개 방식으로 반복한다.

5. 결과 저장
- 완료, 정답 수, 오답 표현, 저장 표현을 반영한다.


4. MVP에서 가능한 실전회화 문제 유형

1) 뜻 고르기
- 영어 표현을 보고 한국어 의미를 고른다.
- 예: What time works for you? -> 몇 시가 괜찮아?
- 난이도: 낮음
- 학습 효과: 표현 인식
- 현재 객관식 구조로 구현 가능

2) 한국어 의미 -> 영어 표현 선택
- 한국어 의미를 보고 알맞은 영어 표현을 고른다.
- 예: 창가 자리 가능할까요? -> Could we have a window seat, please?
- 난이도: 낮음~중간
- 학습 효과: 의미에서 표현 회상
- 현재 객관식 구조로 구현 가능

3) 상황에 맞는 표현 고르기
- 짧은 상황 설명을 보고 가장 자연스러운 표현을 고른다.
- 예: 친구에게 금요일 저녁 식사를 제안한다.
- 정답: Are you free for dinner this Friday?
- 난이도: 중간
- 학습 효과: 상황-표현 연결
- 현재 실전회화와 가장 잘 맞는 기본 유형

4) 다음 대사 고르기
- 직전 대화를 보여주고 다음에 할 말을 고른다.
- 예:
  A: What time works for you?
  You: ?
- 정답: How about seven?
- 난이도: 중간
- 학습 효과: 대화 흐름 이해
- 회화 앱 느낌을 가장 크게 강화하는 유형

5) 빈칸 채우기
- 핵심 표현 일부를 빈칸으로 만들고 알맞은 단어/구를 고른다.
- 예: I'd like to ____ a table for two.
- 정답: book
- 난이도: 중간
- 학습 효과: 표현 패턴 고정
- 단어학습 fill-blank와 유사하게 확장 가능

6) 문장 순서 배열
- 영어 표현 조각을 올바른 순서로 배열한다.
- 예: [you] [for] [What time] [works] [?]
- 정답: What time works for you?
- 난이도: 중간~높음
- 학습 효과: 문장 구조 회상
- 선택형보다 구현 난이도는 높지만 음성 없이 회화감을 줄 수 있다.

7) 표현 패턴 변형
- 배운 표현의 일부만 바꾸어 새 문장을 고른다.
- 예:
  원형: Are you free for dinner this Friday?
  변형: Are you free for coffee tomorrow?
- 난이도: 중간~높음
- 학습 효과: 암기에서 응용으로 이동
- 콘텐츠 작성 품질이 중요하다.


5. 실전회화 추천 문제 구성 예시

Day 1 예시: 친구에게 저녁 약속 잡기

핵심 표현
- Are you free for dinner this Friday?
- What time works for you?
- How about that Italian place near the station?

추천 문제 순서
1. 뜻 고르기
- Are you free for dinner this Friday? 의 뜻을 고른다.

2. 한국어 의미 -> 영어 표현 선택
- "이번 금요일 저녁 시간 있어?"에 맞는 표현을 고른다.

3. 상황에 맞는 표현 고르기
- 친구에게 금요일 저녁 식사를 제안하는 상황에서 자연스러운 문장을 고른다.

4. 다음 대사 고르기
- Channa: What time works for you?
- You: How about that Italian place near the station? Say, seven?

5. 빈칸 채우기
- Are you ____ for dinner this Friday?
- 정답: free

6. 문장 순서 배열
- [Are] [you] [free] [for dinner] [this Friday?]

권장 MVP 구성
- 처음에는 1~4번만 우선 적용한다.
- 5번 빈칸 채우기는 다음 단계에서 추가한다.
- 6번 문장 순서 배열은 UI 작업량이 있으므로 별도 Phase로 뺀다.


6. 권장 JSON 문제 타입 초안

현재
- multiple-choice

추천 확장 타입
- meaning-choice
  - 영어 표현 -> 한국어 뜻 고르기

- ko-to-expression
  - 한국어 의미 -> 영어 표현 고르기

- situation-choice
  - 상황 설명 -> 알맞은 표현 고르기

- next-line-choice
  - 이전 대사 -> 다음 대사 고르기

- expression-fill-blank
  - 표현/문장 빈칸 채우기

- sentence-order
  - 문장 조각 순서 배열

주의
- 처음부터 모든 타입을 구현하지 않는다.
- MVP 1차 확장은 multiple-choice 렌더러를 재사용할 수 있는 타입부터 시작한다.
- sentence-order는 선택지 UI가 다르므로 후순위가 적절하다.


7. 추천 구현 우선순위

1순위: 콘텐츠만으로 다양화 가능한 객관식 계열
- 뜻 고르기
- 한국어 의미 -> 영어 표현 선택
- 상황에 맞는 표현 고르기
- 다음 대사 고르기

2순위: 렌더러 소폭 확장이 필요한 유형
- 빈칸 채우기
- 표현 패턴 변형

3순위: 별도 UI가 필요한 유형
- 문장 순서 배열

후순위: 음성/AI 기반
- TTS 발음 듣기
- 녹음 버튼
- 음성 인식 채점
- AI 대화
- 발음/억양 피드백


8. 결론

단어학습은 이미 "영어 -> 뜻", "뜻 -> 영어", "빈칸"의 3회 반복 구조가 잡혀 있다.
현재 단계에서는 단어학습 문제 유형을 추가하기보다 콘텐츠 품질과 오답/복습 흐름을 유지하는 편이 좋다.

실전회화는 현재 안정적인 MVP 흐름을 갖고 있지만, 문제 풀이가 객관식 하나에 치우쳐 있다.
가장 좋은 개선 방향은 같은 핵심 표현을 뜻, 상황, 다음 대사, 빈칸, 배열 방식으로 반복시키는 것이다.
음성 없이도 "대화하고 있다"는 느낌을 만들려면 다음 대사 고르기와 상황에 맞는 표현 고르기를 우선 추가하는 것이 좋다.
9. 실전회화 실제 적용 방향

이번 실전회화 확장에서는 선택형 퀴즈만 늘리는 대신, 사용자가 대화에 참여한다고 느끼도록 아래 두 유형을 우선 적용한다.

1) next-line-choice
- 상대 대사를 먼저 보여준다.
- 사용자는 이어질 내 대답을 고른다.
- 목적: 스크립트를 읽는 흐름에서 "상대 말에 반응하는 연습"으로 전환한다.
- 저장: 오답은 기존처럼 quiz.id 기준으로 wrongNotes에 저장한다.
- 표현 연결: expressionId로 keyExpressions[].id를 연결한다.

2) pattern-fill-blank
- 단어 하나가 아니라 자주 쓰는 회화 표현 덩어리를 빈칸으로 낸다.
- 예: Are you {{blank}} for dinner this Friday?
- 예: I'd like to {{blank}} a table for two.
- 목적: 문장 전체 암기보다 실제로 자주 쓰는 표현 패턴을 반복한다.
- 저장: 오답은 기존처럼 quiz.id 기준으로 wrongNotes에 저장한다.
- 표현 연결: expressionId로 keyExpressions[].id를 연결한다.

표현 저장 고려
- 표현 저장 버튼은 계속 핵심 표현 카드(keyExpressions)에서 제공한다.
- savedExpressions 구조는 변경하지 않는다.
- 새 퀴즈의 expressionId는 표현 저장 데이터와 직접 병합하지 않고, "이 퀴즈가 어떤 표현을 연습하는지" 알려주는 참조로 둔다.
- 따라서 localStorage key와 UserProgress schemaVersion은 변경하지 않는다.

현재 적용된 추천 패턴
- 각 Conversation Day에 기존 multiple-choice 2문항을 유지한다.
- 각 Day에 next-line-choice 1문항을 추가한다.
- 각 Day에 pattern-fill-blank 1문항을 추가한다.
- 결과 화면과 오답 저장 흐름은 기존 quizCorrect / quizTotal / wrongQuizIds 구조를 유지한다.
