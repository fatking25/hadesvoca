하데스 보카 학습 문제 풀이 패턴 정리
====================================

문서 목적
- 단어학습과 실전회화가 어떤 방식으로 문제를 출제하고 렌더링하는지 정리한다.
- 앞으로 문제를 추가할 때 데이터 의도와 UI 책임을 헷갈리지 않게 한다.


1. 단어학습 현재 구조
--------------------

관련 파일
- public/content/words/stage-1.json
- src/types/content.ts
- src/pages/WordStudyDayDetailPage.tsx

콘텐츠 단위
- Stage
  - Day
    - word
      - questions[]

현재 단어 1개당 기본 문제 패턴
1. word-to-meaning
   - 영어 단어를 보고 한국어 뜻을 고른다.
   - 학습 목적: 단어 인식, 뜻 매칭

2. meaning-to-word
   - 한국어 뜻을 보고 영어 단어를 고른다.
   - 학습 목적: 뜻에서 단어 회상

3. fill-blank
   - 예문의 빈칸에 들어갈 영어 단어를 고른다.
   - 학습 목적: 문맥 속 단어 사용 확인

단어학습 풀이 흐름
1. Day에 포함된 words를 불러온다.
2. 각 word의 questions를 순서대로 quizItems에 넣는다.
3. 사용자는 4지선다 선택지를 고른다.
4. 정답 확인 후 피드백을 본다.
5. 마지막 문제 후 결과 화면으로 이동한다.


2. 실전회화 현재 구조
--------------------

관련 파일
- public/content/conversations/stage-1/index.json
- public/content/conversations/stage-1/day-01.json ... day-07.json
- src/types/conversation.ts
- src/pages/conversation/ConversationDayDetailPage.tsx

Day 흐름
1. 대표 컷씬
2. 나레이션
3. 비주얼노벨식 대화
4. 문장 맞추기 퀴즈
5. 핵심 표현 확인 및 단어장 저장
6. Day 결과/보상

Stage 1 표준 수량
- narrations 2개
- dialogue 6줄
- learner responseQuiz 2개
- keyExpressions 3개
- quiz 4개


3. 대화 중 responseQuiz
----------------------

위치
- ConversationDialogueLine.responseQuiz
- learner 대사에만 붙인다.

역할
- 사용자가 장면 안에서 다음 말을 고르는 흐름이다.
- 정답을 고르면 자연스럽게 해당 learner 대사가 표시된다.
- 오답을 골라도 장면 진행은 막지 않고, 더 자연스러운 대사로 이어진다.

작성 원칙
- 정답 option text는 연결된 dialogue line의 textEn과 같아야 한다.
- promptKo는 앱 기능 설명이 아니라 상황 설명처럼 쓴다.
- 피해야 할 문장:
  - "이 대답이 내 대사로 이어집니다."
  - "내가 고른 답:"
  - "선택 후 다음 대화로 진행됩니다."


4. 실전회화 quiz
---------------

데이터 타입
- multiple-choice
- next-line-choice
- pattern-fill-blank

현재 UI 렌더링
- 모든 실전회화 quiz는 단어 풍선 문장 만들기 방식으로 렌더링한다.
- 사용자는 단어 토큰을 눌러 문장을 배열한다.
- 선택한 토큰은 다시 빼거나 좌우로 순서를 바꿀 수 있다.
- 정답 확인 후 다음 문제로 넘어간다.
- 마지막 quiz 후 결과 화면으로 바로 가지 않고, 핵심 표현/단어장 저장 흐름으로 이동한다.

정답 문장 결정 규칙
- pattern-fill-blank:
  - templateEn의 "{{blank}}"에 correct option text를 넣은 문장
- multiple-choice:
  - promptEn 또는 promptKo에 backtick 문장(`...`)이 있으면 그 문장
  - 없으면 correct option text
- next-line-choice:
  - correct option text


5. 문제 문장 톤
---------------

실전회화는 앱의 조작 설명보다 장면 몰입을 우선한다.

좋은 방향
- "직원이 원하는 시간을 물었습니다. 시간과 좌석 요청을 자연스럽게 말해 보세요."
- "친구가 주말에 영화를 볼 수도 있다고 했습니다. 자연스럽게 함께 가자고 제안하세요."
- "조금 어색해요. 자연스러운 순서는 아래와 같아요."

피해야 할 방향
- "정답입니다. 이 대답이 내 대사로 이어집니다."
- "오답입니다. 정답 대사가 내 대사로 이어집니다."
- "내가 고른 답:"
- "앱에서 다음 단계로 이동합니다."


6. 앞으로의 확장 방향
--------------------

- 단어학습은 현재 객관식 중심 구조를 유지한다.
- 실전회화는 responseQuiz와 quiz를 분리한다.
  - responseQuiz: 대화 중 즉흥 응답 선택
  - quiz: Day 핵심 표현을 문장으로 재조립하는 복습
- 새 Stage를 만들 때는 Day 1만 특별 취급하지 않고, 모든 Day가 같은 표준 수량과 흐름을 갖게 한다.
