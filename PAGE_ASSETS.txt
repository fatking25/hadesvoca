Conversation Pages
------------------

/conversation
- Uses ConversationDay.cutsceneImagePath from assembled ConversationStage.days.
- Source files:
  - public/content/conversations/stage-{stageId}/index.json
  - public/content/conversations/stage-{stageId}/day-{DD}.json
- Rendered as each Day card thumbnail.

/conversation/:dayId
- cutscene step: cutsceneImagePath
- narration step: sceneImages.intro
- dialogue step: sceneImages.dialogue
- quiz step: sceneImages.review
- key expression step: sceneImages.review

Fallback order in detail view
  sceneImages[role].imagePath
  -> cutsceneImagePath
  -> /content/conversations/assets/placeholder-day1-cutscene.svg

Current limitation
- If JSON points to an existing-looking path but the file is missing, the browser can show a broken image.
- There is no dedicated img onError fallback yet.


Conversation Stage Asset Folder Convention
------------------------------------------

Stage-specific conversation assets live next to the Stage JSON files.

  public/content/conversations/
    stage-{stageId}/
      index.json
      day-{DD}.json
      assets/
        stage-{stageId}-day-{DD}-cutscene.jpg
        stage-{stageId}-day-{DD}-scene-01.jpg
        stage-{stageId}-day-{DD}-scene-02.jpg
        stage-{stageId}-day-{DD}-scene-03.jpg

Shared fallback-only assets live here:

  public/content/conversations/assets/

JSON path rules
- All JSON image paths must be site-root paths beginning with /content/...
- cutsceneImagePath is the representative Day thumbnail/card image.
- sceneImages.intro uses scene-01.
- sceneImages.dialogue uses scene-02.
- sceneImages.review uses scene-03.

Recommended paths for Stage 1 Day 1
- /content/conversations/stage-1/assets/stage-1-day-01-cutscene.jpg
- /content/conversations/stage-1/assets/stage-1-day-01-scene-01.jpg
- /content/conversations/stage-1/assets/stage-1-day-01-scene-02.jpg
- /content/conversations/stage-1/assets/stage-1-day-01-scene-03.jpg
